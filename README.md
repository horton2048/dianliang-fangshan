# 《点亮房山》MVP（序章～第三章）

双击 `index.html` 即可在浏览器里玩（无需构建、无需联网）。

## 操作
- 移动：方向键 / WASD；跑步：按住 Shift
- 确认 / 对话 / 打卡：Z 或空格；取消：X
- 地图：M；背包：I；菜单（任务卡、章册、声音）：Enter；静音：N
- 手机：左下虚拟摇杆，A 确认，B 取消（按住 B 跑步），底部有地图、背包、菜单、声音按钮

## 文件
- `index.html` 入口；`game.js` 引擎；`art.js` 代码生成的像素美术（32 色）；`audio.js` WebAudio 芯片音效
- `data.js` 任务卡、NPC 台词、迎新点摊位、路牌、室内场景（补到真实信息后只改这里）
- `mapdata.js` 由 `_tools/build_map.py` 从《手册数据.json》生成：tileX=(X+175)/3+4，tileY=(Z+330)/3+4（1 瓦片=3 游戏米，外圈 4 格为围墙）
- `_tools/` 地图转换脚本、自动化测试脚本、地图预览图（游戏运行用不到）

## 重新生成地图
把 `手册数据.json` 复制成 `../ref/data.json`（相对 `_tools` 的上上级），然后运行 `python3 _tools/build_map.py`。

## 说明
- 报到、领证卡、领物资地点手册里没有，放在旗杆广场迎新点，对话里标注“示意点位，待补真实信息”。
- 图书馆外观暂用“白色圆环＋玻璃”一版（待定版）；建筑轮廓用手册外包框近似，C 形、U 形、L 形是示意，不是测绘。
- 存档在浏览器 localStorage（宿舍床手动存档；进出门、完成任务自动存档）。
